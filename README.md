# Образовательные модули

## Описание

Приложение для обучения

## Содержание

* модуль manage.py в корне проекта
* папка static
* директория config
* директория educational_modules
* директория users
* папка media

1. **educational_modules** содержит модули для функционирования приложения educational_modules, директорию с миграциями

2. **config** с основными настройками проекта

3. **users** отвечает за логику работы с пользователями

    JWT-авторизация реализована при помощи djangorestframework-simplejwt.

4. **static** предназначена для хранения статических файлов

5. **media** предназначена для хранения медиафайлов


*Приложение educational_modules содержит cериализаторы и представления для моделей:*
1. EducationalModule (ViewSet)
2. Topic (ViewSet)
3. Lesson (Generic)

Для списка уроков реализована пагинация (по 5 на странице) и кэширование (Redis)

*Приложение users содержит:*

1. Сериализаторы и представления для модели User
2. Настройку прав доступа для пользователей (группы прав: администратор, модератор, преподаватель, владелец)


Запуск программы осуществляется через модуль manage.py

Документацию по использованию API можно прочесть [тут](http://127.0.0.1:8000/swagger/)

## Запуск проекта с помощью Docker Compose

Этот проект использует Docker Compose для запуска всех необходимых сервисов одной командой. В состав проекта входят:

1. Веб-приложение на Django;
2. PostgreSQL — база данных;
3. Redis — брокер для кэширования страниц;

**Подготовка к запуску проекта:**
1. Установите Docker.
2. Установите Docker Compose.
3. Убедитесь, что Docker запущен и работает.

**Запуск проекта**
1. Клонируйте репозиторий:
```
git clone https://github.com/LukinaGA/educational_modules
cd educational_modules
```
2. Создайте файл .env в корне проекта и добавьте туда необходимые переменные окружения, указанные в файле .env.example.
3. Для доступа к панели администратора в файле users/management/commands/csu.py замените email и password, либо оставьте текущие значения и выполните команду
```commandline
python manage.py csu
```
4. Запустите проект, выполнив команду для запуска в фоновом режиме:
```
docker-compose up -d
```

После запуска веб-приложение будет доступно по адресу: http://localhost:8000, доступ к панели админимстратора - http://localhost:8000/admin/


**Дополнительные команды:**
- Для просмотра запущенных контейнеров:
```
docker-compose ps
```
Для просмотра логов всех контейнеров:
```
docker-compose logs
```
- Для остановки сервисов:
```
docker-compose down
```
